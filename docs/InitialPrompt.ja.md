ブラウザーセレクターアプリ (Preferis) を作りたいので設計の検討をしてください。

## アプリの概要
Preferis は OS のブラウザーとして登録でき、OS シェルから URL リクエストを受け付けたのち、あらかじめ設定されたルールをもとに実際に開くブラウザー(Edge, Chrome...、あるいはプロファイル) を決定し、ブラウザーを起動します。

例えば以下のようなユースケースを想定しています:
- https://www.example.com/ はデフォルトの Microsoft Edge で開き、https://admin.google.com/ は Google Chrome で開く
- https://app1.example.com/ は Google Chrome (Profile: Default) で開き、https://app2.example.com/ は Google Chrome (Profile: AnotherUser) で開く
- https://login.microsoftonline.com/ は開くブラウザーやプロファイルを選択して開く

アプリは設定のための UI をもち、グラフィカルにルールを設定できます。
## 前提
- .NET アプリケーション
- クロスプラットフォーム (Windows, macOS)
- NativeAOT
## 用語
- プロファイル
	- ブラウザーや実行ファイルなど起動対象を表すもの
- ルーティング
	- 入力された URL を元にどのように処理するかの仕組み
- ルーティングルール
	- ルーティングする条件とマッチした時のアクションを定義したもの
	- ルーティングルールは複数持つことができ、最初にマッチしたものが適用される
## 要件
- あくまでトランポリン的なツールなので起動は可能な限り高速にする
	- そのため NativeAOT は必須
	- 設定 UI はその限りではない
- 設定ファイルは Windows と macOS で共通化できる様にしたい
	- 例えば OneDrive, Google Drive といったクラウドストレージで同期するといった使用方法
	- そのためプロファイルにマシンローカルな直接ブラウザーのパスを埋め込むことはできない点を考慮する必要がある (名前で参照するなど)
- ブラウザーとブラウザープロファイルの自動検出
	- 起動対象として選択できるブラウザーは自動検出し、ブラウザーのプロファイル(Preferisのプロファイルではない)も選択できる様にする
## 仕様
以下は現時点で検討した仕様であり、不完全な部分や見落としがある可能性があります。
### ルーティング
ルーティングは複数あるルーティングルールにマッチしたものを実行します。
ルールはトリガーとなる条件とマッチした際のアクションの組み合わせで作られます。
#### 条件
ルーティングに使用できるパターン
- グループ化
	- And
	- Or
- Regex
	- Host (`^[^.]\.example\.(org|com)$`)
	- Url (`^https?://[^.]\.example\.(org|com)/`)
- Wildcard
	- Host (`*.example.com`)
	- Url (`https://example.com/signin/*`)
- StartsWith
	- Host (`www.example`)
	- Url (`https://www.example.com/admin/`)
- EndsWith
	- Host
	- Url
- Contains
	- Host
	- Url
#### アクション
ルーティングルールには複数のアクションを指定することが可能。
- デフォルトまたは指定プロファイルを起動
	- 単一の場合にはそのプロファイルを起動
	- 複数プロファイルの場合にはプロファイル選択UIを表示
- システムに再移譲 (ShellExecute や open コマンド相当)
- 何もしない
- URLをリライト
- 再ルーティング (無限ループしないようにガードが必要)
### キャッチオールルール
ルーティングには最初から存在し、削除できない特別なキャッチオールルールを持ちます。これはどのルールにも当てはまらなかった際にフォールバックされるデフォルトのルールです。

## UI
Preferis は次の2種類のUIを持ちます。
### 設定 UI
設定は以下の設定を行えます。
- プロファイル
- ルーティングルール
### プロファイル選択 UI
プロファイル選択 UI はルーティング先候補が複数ある場合に表示されるダイアログ UI です。これは Windows でアプリを選択する UI と似ていると考えることができます。
