## When a profile's browser is unavailable

You can choose a fallback profile to use when a profile's configured browser is unavailable.

For example, a profile configured to use Google Chrome cannot be used on another device without Google Chrome installed, even if the configuration is shared. A fallback lets you use an alternative profile in that situation.

![](/img/docs/settings-profile-adv-01.png)

:::tip
For most cases, the settings described in [Sharing Configuration Across Devices](../sharing-configuration-across-devices.md) are sufficient.
:::

## Profile IDs

Each profile has an ID in the configuration file. You can change it in the settings window.

![](/img/docs/settings-profile-adv-02.png)

You normally do not need to change this ID.
