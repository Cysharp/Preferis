---
title: Running Commands
---

Profiles can run an OS command to handle a URL instead of opening it in a browser.

:::danger
Incorrect argument handling, either when passing arguments or in the program that receives them, could allow malicious code to run. Take care when configuring commands.
:::

Select **Command** for the profile's **Opens with** option to run a command instead of a browser.

![](/img/docs/settings-profile-command-01.png)

You can configure the following:

- Program path on Windows
- Arguments on Windows
- Program path on macOS
- Arguments on macOS

![](/img/docs/settings-profile-command-02.png)
