---
title: Choosing Between Multiple Profiles
---

If you select multiple profiles for a rule, opening a matching URL displays the profile picker so you can choose which profile to use.

![](/img/docs/profile-picker-01.png)

:::tip
Profiles appear in the picker in the same order as the profile list. To change the order, drag and drop profiles in the list on the Profiles settings page.
:::

Select **Always open &lt;domain&gt; with this choice** before opening the URL to automatically add a rule for that domain.

## Settings

Select **General** in the settings sidebar and use the **Picker** section to customize its behavior.

### Position

Choose where the picker initially appears:

- **Near the pointer** (default): Appears at the mouse pointer's location.
- **Center of the screen**: Always appears in the center of the screen.

### Choose automatically after

Set the number of seconds before the picker automatically chooses a profile and closes. A value of 0 disables this feature (the default).

When the time elapses, the URL opens with the profile currently selected in the picker. The first profile is selected by default.
