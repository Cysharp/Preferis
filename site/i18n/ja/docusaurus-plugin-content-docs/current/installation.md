Preferis は以下の手順でインストールできます。

## Windows へのインストール

1. GitHub の [リリースページ](https://github.com/cysharp/Preferis/releases) から最新のインストーラー (`Preferis-win-x64-Setup.exe` または `Preferis-win-arm64-Setup.exe`) をダウンロードします
    - x64 と Arm 向けのインストーラーが用意されているので利用している環境に合わせてダウンロードしてください
2. ダウンロードしたインストーラーを実行し、画面の指示に従ってインストールを完了させます
    - Preferis は現在のユーザー向けに `%LOCALAPPDATA%\Preferis` へインストールされます。管理者権限は必要ありません
    - インストールが完了すると設定画面が開き、スタートメニューに Preferis が追加されます

:::caution
現在 Windows 版のインストーラーと実行ファイルはコード署名されていないため、インストーラーの実行時に Windows SmartScreen の警告が表示されることがあります。「詳細情報」から「実行」を選択して続行してください。これは将来的に解消される可能性があります。
:::

### ポータブル版

インストールせずに使う場合は、代わりに `Preferis-<バージョン>-win-x64.zip` (または `win-arm64`) をダウンロードし、中に入っている `Preferis` フォルダーを任意の場所に展開します。そのフォルダーの `Preferis.exe` を実行すると設定画面が開くので、Preferis を既定のブラウザーとして設定してください。

ポータブル版は自動では更新されません。更新するには新しいバージョンを同じフォルダーに上書きで展開します。設定はフォルダーの外に保存されているため、そのまま保持されます ([設定ファイル](configuration-files.md) を参照)。

## macOS へのインストール

1. GitHub の [リリースページ](https://github.com/cysharp/Preferis/releases) から最新の .dmg ファイルをダウンロードします
2. ダウンロードしたディスクイメージから Preferis をアプリケーションフォルダにドラッグします
3. ターミナルで `xattr -cr /Applications/Preferis.app` を実行して、ダウンロード時のセキュリティ属性を削除します

:::caution
現在 macOS 版の Preferis は署名や Apple による公証 (Notarization) が行われていないため、ダウンロード後に上記の手順を行う必要があります。これは将来的に解消される可能性があります。
:::

## 更新

- **Windows (インストーラーでインストールした場合)**: Preferis 自身で更新できます。設定画面のサイドバーで「一般」を選択し、ページ末尾の「更新」を使います。「更新を確認」で GitHub の最新リリースを調べ、「ダウンロード」で取得し、「再起動して更新」でインストールして Preferis を再起動します。設定と既定のブラウザーの登録はそのまま保持されます
- **Windows (ポータブル版)** と **macOS**: リリースページから新しいバージョンをダウンロードし、以前のものと置き換えます (macOS では新しい Preferis をアプリケーションフォルダにドラッグし、`xattr` の手順をもう一度行います)。設定は保持されます

:::note
更新の確認は GitHub の Preferis のリリースを読みに行きます。リポジトリが非公開の間は「404 (Not Found)」で失敗するため、その場合はリリースページから新しいインストーラーをダウンロードしてください。
:::
