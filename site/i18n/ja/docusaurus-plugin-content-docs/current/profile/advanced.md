## プロファイルのブラウザーが使用できないときの設定
プロファイルで指定されたブラウザーが使用できないときにフォールバックするプロファイルを設定できます。

例えば Google Chrome を使用するプロファイルを作成していたとして、他のデバイスと設定を共有した際に他のデバイスには Google Chrome がインストールされていないとプロファイルは使用できなくなります。そこでこの設定では代わりとなる設定がある場合にはそれを使用するといったことが可能です。

![](/img/docs/settings-profile-adv-01.png)

:::tip
ほとんどのケースでは「[複数のデバイスで設定を共有する](../../share-config-across-devices)」にある設定で十分カバーできます。
:::

## プロファイルの ID
プロファイルは設定ファイル内に ID を持ち、設定画面ではこれを変更できます。

![](/img/docs/settings-profile-adv-02.png)

通常、このプロファイル ID を変更する必要はありません。
