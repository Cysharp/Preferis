---
title: コマンドを実行する
---

プロファイルの設定では URL を開く操作としてブラウザーを使用する以外に OS のコマンドを実行することも可能です。

:::danger
引数での渡し方を誤ったり、プロセス側での処理の仕方が不適切な場合に悪意あるコードが実行できる可能性があります。十分注意してください。
:::

プロファイルの「リンクを開く対象」として「コマンド」を選択することでブラウザーの代わりにコマンドの実行が可能となります。

![](/img/docs/settings-profile-command-01.png)

コマンドには以下の設定が可能です:

- Windows 上でのプログラムの場所
- Windows 上での引数
- macOS 上でのプログラムの場所
- macOS 上での引数

![](/img/docs/settings-profile-command-02.png)
