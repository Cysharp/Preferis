---
title: 様々なアクション
---

ルールのアクションにはプロファイルを開く以外にも URL の書き換えなどいくつかのアクションが用意されています。「アクションを追加」ボタンをクリックすると追加できます。

![](/img/docs/settings-rule-actions-01.png)

アクションは複数登録できますが、終端となるものと後続のアクションに続くものの2種類があります。例えば「プロファイルで開く」は終端のアクションですが「URL を書き換える」は後続のアクションに続きます。

## プロファイルで開く
選択したプロファイルで URL を開くアクションです。このアクションで処理は終了します。

## URL を書き換える
入力された URL を書き換えます。書き換え方法としては以下の2種類があります。

- 正規表現による置換
- クエリーパラメータを URL へ変換
    - 例えば `?url=https%3A%2F%2Fmysite.example%2F&foo=bar` のようなクエリーから `url` の値を取り出します

このアクションは後続のアクションに続きます。

## 最初のルールから振り分け直す

ルールの判定を最初からやり直します。例えば URL の書き換えを行った後に再度ルールのマッチを再評価したいといった場合に使用します。このアクションで処理は終了します。

## OS 既定のハンドラーに渡す

OS のハンドラーに渡します。これは例えば独自スキームに書き換えた場合など、Preferis が開けないものを OS に任せるために使用できます。このアクションで処理は終了します。

## 何もしない

受け取った URL に対して何も行わずルールのアクション処理を終了します。このアクションで処理は終了します。
