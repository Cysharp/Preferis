---
title: 条件の比較
---

Preferis に渡されたホストや URL をルールの条件で比較する際には次のものを使用できます。

:::tip
大文字小文字を区別するかどうかは入力の種類によります。例えば「ホスト」「URL」「アプリ ID」「アプリのパス」は常に大文字小文字を区別しませんが、「URL (大文字と小文字を区別)」は区別されます。
:::

## 次と等しい
入力が指定した値と完全に一致しているかどうかを判定します。

例えば `app.example` は入力 `app.example` に一致します。

## 次で始まる
入力が指定した値で始まっているかどうかを判定します。

例えば `app.example` は入力 `app.example` や `app.example.com` に一致します。


## 次で終わる
入力が指定した値で終わっているかどうかを判定します。

例えば `app.example` は入力 `app.example` や `myapp.example` に一致します。

## 次を含む
入力が指定した値を含むかどうかを判定します。

例えば `app.example` は入力 `app.example` や `myapp.example`、`myapp.example.com` に一致します。

## 次のパターンに一致
入力が指定した値のパターンに一致するかどうかを判定します。パターンでは `*` が任意の文字列に一致し、`?` が任意の1文字に対応します。

例えば `*.example` は入力 `sub.example` に一致し、`app?.example` は入力 `app1.example` や `app9.example` に一致します。

## 次の正規表現に一致
入力が指定した正規表現に一致するかどうかを判定します。正規表現は .NET の正規表現パターンエンジンを使用したものとなります。
