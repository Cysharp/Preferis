---
title: 複数のプロファイルから選択して開く
---

ルールでマッチした際の開くプロファイルを複数を選択すると、URL を開いた際にプロファイルピッカーが表示されて任意のプロファイルを選択して URL を開けます。

![](/img/docs/profile-picker-01.png)

:::tip
ピッカーのプロファイル並び順はプロファイル一覧の並び順です。プロファイルの並び順はプロファイル設定画面の一覧でドラッグアンドドロップを使用して変更できます。
:::

「Always open &lt;domain&gt; with this choice」にチェックを入れて開くと、そのドメインに対応するルールが自動的に追加されます。

## 設定
設定画面のサイドバーの「一般」から「ピッカー」で各種設定をカスタマイズ可能です。

### 表示位置

ピッカーが表示される際の初期表示位置を以下のいずれかに変更できます。

- **ポインターの近く** (デフォルト): マウスポインターの位置に表示されます
- **画面の中央**: 常に画面中央に表示されます


### 一定時間で自動的に閉じる
自動で選択して閉じるまでの秒数を設定できます。0 を指定した場合はこの機能は無効です(デフォルト)。

指定した秒数が経過するとピッカーで選択中のプロファイルで URL を開きます。既定では先頭のプロファイルが選択されます。
